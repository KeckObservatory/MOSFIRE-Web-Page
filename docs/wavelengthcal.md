# Wavelength Calibration

Below are arc and night sky line lists for use with wavelength calibration. These are arc line lists for the Neon and Argon lamps used for MOSFIRE wavelength calibration. The arc line list is based on laboratory data acquired before commissioning.

Line lists for the observed night sky were determined using night sky spectra obtained during the "second light" observing run, 3-8 May 2012. ASCII files and plots are provided.

These lists were developed and graciously provided by Dr. C. Steidel (MOSFIRE team).
